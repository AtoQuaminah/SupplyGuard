# Limitations

This project is intentionally conservative and static-only.

- It does not execute candidate code.
- It does not install or import package modules.
- It does not provide full vulnerability triage beyond static heuristics.
- It does not claim to be a full malware classifier, and it does not use ML.
- Deterministic scoring is configuration-based and should be treated as an implementation baseline unless a future evaluation justifies a different policy.
